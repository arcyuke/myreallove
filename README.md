# Олег + Настя — наша история

Сайт к полутора годам отношений. Чистый HTML, CSS и JavaScript; работает на GitHub Pages без установки библиотек.

## Фото и видео

Загружайте файлы в корень репозитория или в любые папки, например `media/`. Существующие файлы сайта удалять не нужно. После загрузки GitHub Actions собирает список медиа и обновляет сайт.

| Момент | Названия без расширения |
| --- | --- |
| Предложение встречаться | `nachalo1` — фото |
| Футболки | `shirt1`, `shirt2` — фото |
| Видео в наушниках | `dorogo1` — видео |
| Фотосессия | `session1` … `session15` — фото |
| Концерт | `kpss1` … `kpss3` — фото; `kpss1`, `kpss2` — видео |
| Год отношений | `god1` — видео |
| После дня рождения | `posle1` … `posle20` — фото |
| Финальная лента | `love1` … `love30` — фото |

Поддерживаются JPG/JPEG, PNG, WebP, AVIF, GIF и MP4, WebM, MOV, M4V, OGV. Для телефона лучше всего JPG и MP4 с H.264/AAC. HEIC сначала сохраните как JPG. Одинаковый номер фото и видео допустим: `kpss1.jpg` и `kpss1.mp4` не путаются. Пробелы, дефисы, подчёркивания и регистр не мешают: `kpss 1.JPG` тоже найдётся. Старайтесь не загружать два фото с одинаковым названием в разные папки.

В лентах показываются только доступные фотографии. Пока файлов нет, стоят аккуратные карточки воспоминаний. Они заменяются фотографиями при следующем открытии страницы после публикации.

## Публикация

В настройках репозитория откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**. Затем во вкладке **Actions** запустите **Publish our story → Run workflow**. Последующие загрузки файлов в `main` обновляют сайт автоматически.

Адрес: https://arcyuke.github.io/myreallove/

## Тексты и даты

Главы, подписи и достижения находятся в `story.js`. Знакомство — 5 февраля 2025, начало отношений — 16 марта 2025. Срок с момента знакомства считается автоматически по Новосибирску. У `dorogo1` нет противоречивой подписи «1 год и 10 месяцев»; её можно уточнить отдельно.

Стрелки клавиатуры листают главы. В фотографиях работают стрелки и свайп. Escape закрывает окно. Звуки включаются кнопкой в шапке. Системная настройка уменьшения анимаций поддерживается.
