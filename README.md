# Олег + Настя — наша история

Сайт к полутора годам отношений. Чистый HTML, CSS и JavaScript; работает на GitHub Pages без установки библиотек.

## Фото и видео

Загружайте файлы в корень репозитория или в любые папки, например `media/`. Существующие файлы сайта удалять не нужно. После загрузки GitHub Actions собирает список медиа и обновляет сайт.

| Момент | Названия без расширения |
| --- | --- |
| Предложение встречаться | `nachalo1` — фото |
| Футболки | `shirt1`, `shirt2` — фото |
| Первая ночёвка и рассвет | `rasvet1` … `rasvet4` — фото |
| 10 месяцев, видео в наушниках | `dorogo1` — видео |
| Фотосессия | `session1` … `session8` — фото |
| Её день рождения | `dree`, `dree1`, `dree2`, `dree4` — все найденные фото |
| Концерт | `kpss1` … `kpss3` — фото; `kpssvideo` — одно видео |
| Год отношений | `god1` — видео |
| Мой день рождения | `blaze` — фото |
| После дня рождения | `posle1` … `posle24` — фото |
| Алтай | `altai` и `altai1` … `altai13` — фото |
| Финальная лента | 30 кадров из уже загруженных альбомов, включая `love1` |
| Бонус после финальной ленты | `lovevideo` — видео |

Поддерживаются JPG/JPEG, PNG, WebP, AVIF, GIF и MP4, WebM, MOV, M4V, OGV. Для телефона лучше всего JPG и MP4 с H.264/AAC. HEIC сначала сохраните как JPG. Одинаковый номер фото и видео допустим: `kpss1.jpg` и `kpss1.mp4` не путаются. Пробелы, дефисы, подчёркивания и регистр не мешают: `kpss 1.JPG` тоже найдётся. Старайтесь не загружать два фото с одинаковым названием в разные папки.

В лентах показываются только доступные фотографии. Пока файлов нет, стоят аккуратные карточки воспоминаний. Они заменяются фотографиями при следующем открытии страницы после публикации.

Количество снимков определяется по фактическим файлам, включая названия без номера и с пропусками в нумерации. Поэтому отсутствие `dree3` не мешает показать остальные снимки, а новые `posle` или `altai` подхватятся автоматически.

Четыре видео подключены из [папки Google Диска](https://drive.google.com/drive/folders/1HDHK47GeQa9f2mKspZR38dvV3Zw0q8mJ): `dorogo1` — на 10 месяцев, `god1` — на год отношений, `kpssvideo` — концерт, `lovevideo` — бонус в конце. Ссылки на отдельные файлы находятся в `videos.js`. Для просмотра нужен доступ «Все, у кого есть ссылка» с ролью «Читатель» и завершённая обработка роликов. Сайт открывает их во встроенном плеере Google Диска; под ним есть ссылка для открытия отдельно. При переходе к другой главе воспроизведение останавливается. Если ссылка не задана, работает прежний поиск видео в репозитории.

## Публикация

В настройках репозитория откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**. Затем во вкладке **Actions** запустите **Publish our story → Run workflow**. Последующие загрузки файлов в `main` обновляют сайт автоматически.

Адрес: https://arcyuke.github.io/myreallove/

## Тексты и даты

Главы, подписи и достижения находятся в `story.js`. Знакомство — 5 февраля 2025, начало отношений — 16 марта 2025. Срок с момента знакомства считается автоматически по Новосибирску. Видео `dorogo1` посвящено 10 месяцам отношений.

Стрелки клавиатуры листают главы. В фотографиях работают стрелки и свайп. Escape закрывает окно. Звуки включаются кнопкой в шапке. Системная настройка уменьшения анимаций поддерживается.

## Маленькое приключение

Игра открывается в седьмой главе, «Маленькая передышка». На компьютере играют двое на одной клавиатуре: Олег — WASD, удар F, рывок G; Настя — стрелки, удар Enter, рывок правым Shift. На телефоне можно выбрать одного героя и играть экранными кнопками; второй помогает автоматически. P или кнопка ставит игру на паузу. К истории можно вернуться в любой момент.

Пять этапов: гробница и ключ, медведь, полёт на НЛО, пришельцы и финальный босс. Сердечки восстанавливают общее здоровье. Завершённый этап сохраняется в этом браузере; после проигрыша повторяется текущий этап. За победу показывается исходная десятисекундная гифка `game/happy-ending.gif`.

В историях примерно каждые 15 секунд герои бегут друг к другу с пиццей и энергетиком, обмениваются угощениями и репликами. В открытой игре и диалогах встречи приостанавливаются. Настройка уменьшения анимаций учитывается.

Фоны `game/worlds.webp` и спрайты `game/enemies.webp` подготовлены через ImageGen. Краткий художественный запрос: четыре пиксельных арены (гробница, лес, космос, чужая планета) в бордово-розовой палитре; восемь поз скелета, медведя, пришельца и короля скелетов на зелёном фоне для сборки спрайтов. Для героев используется существующая текстура персонажей сайта.
